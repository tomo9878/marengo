§7 悪路行軍 (Cross-country) ✅ OK
リザーブ↔隣接リザーブ、またはリザーブ↔アプローチ。敵占拠ロケールへは不可。防御行軍条件を満たせばCP不要。1アクションに最大3駒（同一ポジション・同一目的地）。
CP消費 ロケール制限 混乱駒は不可
§8 道路行軍 (Road March) ✅ OK
リザーブからのみ開始。最大3ロケール。主要道路のみ＝CP不要、側道含む＝1CP。横断・交通制限に従いステップ単位で解決。1アクション1駒。
横断/交通制限 道路行軍急襲(騎兵) 継続行軍 増援進入
§16 アプローチクリーンアップ ✅ OK
ターン開始時（自分の駒のみ）。アプローチをブロックしており向かい側が敵に占拠されていない駒をリザーブへ戻す。

急襲・突撃・道路行軍・悪路行軍をリザーブで終了した騎兵が追加でアプローチをブロックできる。CP不要（複数先は1CP/追加）。道路行軍後はその道路方向のみ。

§9 急襲 (Raid) ✅ OK
非ブロック/部分ブロックのアプローチを通過してロケール奪取。防御応答あり（リザーブ起点の場合）。勝敗判定：完全ブロック→防御勝ち。部分ブロック+1体+最初の急襲→防御勝ち。
narrow/wide 士気投入(防御勝利) 退却(攻撃勝利) 継続行軍 道路行軍急襲
§8 道路行軍急襲 (Road March Raid) ✅ OK
道路行軍中の騎兵が敵占拠ロケールに進入を試みる。勝利→行軍継続可（さらに急襲可）。敗北→攻撃元で終了。横断は1ターン1回のみ使用可。急襲後は faceUp=true。
✅ ActionPanel.js: road_march + raidTargetLocaleId がある場合に「⚔ 急襲 → [ロケール名]」バッジをボタンに表示。

§11 突撃 (Assault) ✅ OK
完全/部分ブロックされた敵アプローチを越えてロケール奪取。5ステップフロー：①防御先導駒宣言→②攻撃先導駒宣言→③防御砲撃→④カウンター→⑤戦力減少。
防御先導駒 攻撃先導駒 防御砲撃 カウンター 戦力減少 士気投入 退却(勝利時)
§11-2 防御先導駒宣言 ✅ OK
防御アプローチの駒から選択。narrow:0〜1個、wide:0〜2個。2個は同一兵種。戦力2以上必須。騎兵障害物があれば騎兵不可。
narrow/wide 騎兵障害物
§11-3 攻撃先導駒宣言 ✅ OK
攻撃アプローチから選択。narrow:1個必須、wide:1〜2個。2個は同一兵種。戦力2以上必須（防御側と異なり0個は不可）。
narrow/wide 騎兵障害物
§11-4 防御砲撃 ✅ OK
防御側突撃駒に砲兵がいて先導駒でない場合、攻撃側先導駒1体を即座に1戦力減少。前ターンに砲撃宣言/完遂した砲兵は不可。攻撃側アプローチに砲兵ペナルティがある場合も不可。
砲兵 砲撃状態 砲兵ペナルティ
§11-5 カウンター攻撃 ✅ OK
先導駒でない突撃駒から選択。narrow:最大1個、wide:最大2個。2個は同一兵種。戦力2以上。即座に攻撃先導駒の数だけ減少。
戦力減少に連動 騎兵障害物
§11-6,7,8 勝敗計算 / 戦力減少 ✅ OK
攻撃先導戦力 − ペナルティ − 防御先導戦力 − カウンター戦力 ≥1 → 攻撃勝ち。双方：相手先導駒数だけ減少（先導→余剰は突撃駒へ）。攻撃側：+生存防御騎兵カウンター数。
士気損失(敗者) 退却(攻撃勝利)
§10 砲撃 (Bombardment) ✅ OK
砲兵のみ、アプローチから実施。CP不要。今ターン宣言→次ターン完遂の2ターン行動。防御側が被弾駒を選択（優先順：向かい側AP→リザーブ→その他AP）。
砲兵のみ 砲兵ペナルティ 士気損失 faceUp宣言

§18 定期士気更新 ✅ OK
各プレイヤーのターン開始時に、タイムトラック上の現ラウンドの士気トークンを未投入エリアへ移す（scenarios.json の timeTrack で設定）。

§18 士気投入 ✅ OK
防御側勝利時にロケールへトークンを置く。急襲：wide+2体攻撃+最初の急襲→2枚、それ以外→1枚。突撃：先導駒+カウンター駒数。オーストリア退却：退却駒数。未投入不足時→MORALE_TOKEN_REMOVAL。
急襲防御勝利 突撃防御勝利 オーストリア退却 TOKEN_REMOVAL
§18 士気損失 ✅ OK
砲撃・退却・突撃の戦力減少1につき士気-1（突撃勝者は除く）。未投入から先に除去→不足分→MORALE_TOKEN_REMOVAL（相手がマップトークンを選んで除去）。
砲撃 退却減少 突撃減少(敗者) TOKEN_REMOVAL 士気崩壊→即勝利
§18 士気クリーンアップ ✅ OK

§14 フランス軍の混乱 (Disorder) ✅ OK
ラウンド1のみフランスはアプローチをブロック不可。序盤のフランス駒は全て混乱状態（攻撃不可・現在のロケールから出られない）。再編成アクションで通常状態へ。混乱駒がいるロケールへ進入→全駒が混乱伝染。
悪路行軍制限 再編成で解除 退却後も混乱継続
§15 増援進入 ✅ OK
オーストリア：ターン中に任意で入場（砲兵はラウンド2以降）。舟橋ボーナスで通常+1駒。フランス：ターン開始時に自動進入。入場後1〜2ステップの道路行軍付与。進入ロケールへの敵侵入禁止。
交通制限 道路行軍 進入ロケール保護
§17 シャッフル ✅ OK
同じポジション・保持エリア内の複数駒を混ぜて隠蔽を回復。いつでも可能（相手ターン中も）。ただしアクション済み駒と未アクション駒を混ぜることは不可。
情報隠蔽
§14 再編成 (Reorganize) ✅ OK
フランスのみ。再編成済み2体以下→1体を再編成、3体以上→2体を再編成。同一ターン中に他のアクション可（SP要）。同じロケールでなくてもよい。
